# Contributing to the Incident Response Playbook Generator

Thank you for your interest in contributing to the Incident Response Playbook Generator.

This project welcomes improvements that make the tool more useful, accurate, secure, and accessible to cybersecurity analysts, students, SOC teams, and organisations.

## Ways to Contribute

You can contribute by:

- Adding new incident response templates
- Improving existing playbook actions
- Fixing bugs
- Improving input validation
- Adding automated tests
- Improving documentation
- Adding new export formats
- Suggesting security or usability improvements
